# Linux command cheat sheet (Task 2)
| Command | Purpose | Example |
|---|---|---|
| pwd | print current directory | `pwd` |
| cd | change directory | `cd /tmp`, `cd ..` |
| ls | list files | `ls -la` |
| cat | show file | `cat a.txt` |
| sudo | run as administrator | `sudo apt update` |
| man | manual page | `man ls` |
| redirection | `>` overwrite, `>>` append, `<` input, `\|` pipe | `ls > out.txt` |
| mkdir / rmdir | make / remove empty dir | `mkdir -p a/b` |
| rm | remove | `rm -r folder` |
| cp / mv | copy / move or rename | `cp a b`, `mv a b` |
| file | detect type | `file a.bin` |
| more / less / head | view files | `less big.txt`, `head -n 5 a` |
| alias | shortcut | `alias ll='ls -l'` |
| shutdown / restart | power | `sudo shutdown -h now`, `sudo reboot` |
| touch | create empty file | `touch a.txt` |
| nano | editor | `nano a.txt` |
| bash / sh | run scripts | `bash run.sh` |
| chmod | permissions | `chmod +x run.sh` |
| ps / kill | processes | `ps aux`, `kill 1234` |
| dpkg | Debian packages | `dpkg -l`, `sudo dpkg -i x.deb` |
